Comparison Between AOM 1.0 and AOM 2.0
======================================

Do I Need to Be Authorized to Use AOM 2.0 While I Already Have AOM 1.0 Permissions?
-----------------------------------------------------------------------------------

AOM 2.0 billing is different from AOM 1.0 billing. If you switch from AOM 1.0 to AOM 2.0 for the first time, apply for the permission to use AOM 2.0 by referring to :ref:`Subscribing to AOM 2.0 <aom_03_0001>`.

What Are the Function Differences Between AOM 2.0 and AOM 1.0?
--------------------------------------------------------------

Based on AOM 1.0 functions and common application monitoring, AOM 2.0 collects and monitors more metrics and log data, and displays monitoring results in a visualized manner. For details, see :ref:`Comparison Between AOM 1.0 and AOM 2.0 <aom_01_0027>`.

As AOM 1.0 functions are gradually replaced by AOM 2.0, AOM 1.0 will be brought offline soon. You are advised to upgrade AOM 1.0 to AOM 2.0. For details, see :ref:`Migrating Data from AOM 1.0 to AOM 2.0 <mon_01_0054>`.
