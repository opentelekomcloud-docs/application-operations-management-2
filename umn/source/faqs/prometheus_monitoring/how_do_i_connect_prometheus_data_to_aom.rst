How Do I Connect Prometheus Data to AOM?
========================================

To connect Prometheus data to AOM, do as follows:

#. Create a Prometheus instance.

   For details, see :ref:`Managing Prometheus Instances <mon_01_0072>`.

#. Report native Prometheus metrics to AOM through the remote write address. For details, see :ref:`Configuring the Remote Write Address to Report Self-Built Prometheus Data to AOM <mon_01_0076>`.
