Obtaining the Silence Rule List
===============================

Function
--------

This API is used to obtain the silence rule list.

Calling Method
--------------

For details, see :ref:`Calling APIs <aom_04_0057>`.

URI
---

GET /v2/{project_id}/alert/mute-rules

   | Parameter       | Mandatory       | Type            | Description                                                                   |
   +=================+=================+=================+===============================================================================+
