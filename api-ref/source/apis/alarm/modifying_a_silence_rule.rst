Modifying a Silence Rule
========================

Function
--------

This API is used to modify a silence rule.

Calling Method
--------------

For details, see :ref:`Calling APIs <aom_04_0057>`.

URI
---

PUT /v2/{project_id}/alert/mute-rules

Example Requests
----------------

Modify a silence rule whose name is "32255", time zone is "xxx", and user ID is "2xxxxxxxxxxxxxxxxxxxxxxxxxcf".

.. code-block::

   https://{endpoint}/v2/{project_id}/alert/mute-rules

   {
     "create_time" : 1668147671966,
     "desc" : "",
     "match" : [ [ {
       "key" : "event_severity",
       "operate" : "EQUALS",
       "value" : [ "Info" ]
     } ] ],
     "mute_config" : {
       "ends_at" : 86399,
       "scope" : [ ],
       "starts_at" : 0,
       "type" : "DAILY"
     },
     "name" : "32255",
     "timezone" : "xxx",
     "update_time" : 1668147671966,
     "user_id" : "2xxxxxxxxxxxxxxxxxxxxxxxxxcf"
   }
